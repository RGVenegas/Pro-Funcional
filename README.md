## Gym Management SaaS UI

Aplicacion de gestion para gimnasios con panel de miembros, personal, membresias, clases y seguimiento de entrenamientos.

## Ejecutar el proyecto

Ejecuta `npm install` para instalar las dependencias.

Ejecuta `npm run dev` para iniciar el servidor de desarrollo.

> Importante: no abras `index.html` con doble clic. Este proyecto usa React, TypeScript y Vite, por lo que necesita ejecutarse con `npm run dev`.

Luego abre la URL que muestre Vite, normalmente `http://127.0.0.1:5173/`. Si ese puerto esta ocupado, Vite usara otro.

## Usuarios de demostracion

El login actual funciona como una demostracion local y acepta cualquier correo y contrasena no vacios.

| Perfil | Correo | Contrasena | Vista |
| --- | --- | --- | --- |
| Miembro | `miembro@profuncional.cl` | `miembro123` | Panel de usuario |
| Personal | `personal@profuncional.cl` | `personal123` | Panel administrativo |

Para probar un registro nuevo, selecciona **Registrarme** y completa tus datos, membresia y clases.
